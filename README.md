# midias_usewear

Mídias públicas da loja UseWear (Nuvemshop), servidas via jsDelivr.

| Arquivo | URL |
| --- | --- |
| `videos/hero.mp4` | https://cdn.jsdelivr.net/gh/VonoxDeveloper/midias_usewear@main/videos/hero.mp4 |
| `videos/hero-celular.mp4` | https://cdn.jsdelivr.net/gh/VonoxDeveloper/midias_usewear@main/videos/hero-celular.mp4 |

`hero.mp4` é 1920×1080, ampliado do original de 720p com Real-ESRGAN (`realesr-animevideov3`, 2×).
`hero-celular.mp4` é o corte quadrado central do mesmo vídeo ampliado (900×900), para o hero do celular.

Ao trocar um arquivo, use um nome novo (ex.: `hero-v2.mp4`) ou purgue o cache em
`https://purge.jsdelivr.net/gh/VonoxDeveloper/midias_usewear@main/videos/hero.mp4`.
